# Asset Care Connect

A maintenance management app for wastewater plant assets, PM scheduling, pulling maintenance information from equipment websites, and writing work orders.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
